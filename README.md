# Yatharth Goyal — Engineering Portfolio

An editorial React/Vite portfolio for Java, frontend development, backend systems and dependable full-stack applications. Five real HTML entry points cover the homepage, AegisED, EvalForge, Grid Flex and EduPredict AI.

## Develop

```text
npm ci
npm run dev
npm run build
npx tsc --noEmit
```

## Content and artifacts

- `public/data.js`: factual project context, public evidence links and current education.
- `src/App.tsx`: homepage, case studies, navigation, filters and download controls.
- `styles.css`: responsive graphite/ivory visual system with reduced-motion support.
- `scripts/build_resume_assets.py`: two editable single-column resumes and matching searchable PDFs.
- `scripts/check_assets.py`: one-page, text, hyperlink, editability and factual regression gate.
- `public/resume/`: linked Software Engineer resume (DOCX/PDF) plus archived AI/ML assets retained for backward compatibility.

No employment or unverified certifications are claimed. EduPredict AI is a student-support decision aid; assessments and model outputs are not independently validated real-world dropout predictions. Project test numbers are documented local results, not portfolio-run tests.

See [QA results](QA_RESULTS.md), [evidence boundaries](EVIDENCE_CHANGES.md), [changes](CHANGELOG.md), and [deployment instructions](DEPLOYMENT.md). AegisED's actual repository screenshot is attributed in its case study; architecture diagrams are labeled conceptual.

## Software engineering focus

The public portfolio presents a single Software Engineer career direction: Java, React, Node.js/Express, SQL, accessibility and backend reliability. AegisED is presented as a full-stack application using PostgreSQL (not MongoDB); its ML evaluation scores are intentionally not part of the recruiter-facing website. EvalForge emphasizes durable jobs and distributed backend workflows; EduPredict AI emphasizes React dashboards, FastAPI-backed assessment records and student-scoped intervention workflows. The public resume links only the Software Engineer variant.

After updates to `scripts/build_resume_assets.py`, regenerate the public SDE PDF/DOCX through the controlled build workflow and review the generated files before publication.
