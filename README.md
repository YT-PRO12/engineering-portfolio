# Yatharth Goyal — Engineering Portfolio

An editorial React/Vite portfolio for Java, backend systems and applied AI. Five real HTML entry points cover the homepage, AegisED, EvalForge, Grid Flex and RouteGuard 2.0.

## Develop

```text
npm ci
npm run dev
npm run build
npx tsc --noEmit
```

## Content and artifacts

- `public/data.js`: factual project context, public evidence links and current education.
- `src/App.tsx`: homepage, case studies, navigation, filters and download controls.
- `styles.css`: responsive graphite/ivory visual system with reduced-motion support.
- `scripts/build_resume_assets.py`: two editable single-column resumes and matching searchable PDFs.
- `scripts/check_assets.py`: one-page, text, hyperlink, editability and factual regression gate.
- `public/resume/`: downloadable SDE/Backend and AI/ML DOCX/PDF pairs.

No employment or unverified certifications are claimed. RouteGuard remains in progress; its 95%+ per-class precision/recall goal is an unachieved research target. Project test numbers are documented local results, not portfolio-run tests.
