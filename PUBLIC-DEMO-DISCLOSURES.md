# Public demo disclosures

Recruiter-facing links must accurately describe what is open to the public.

- **AegisED:** an interactive guest walkthrough with synthetic data is not unrestricted access to the authenticated hospital operations service.
- **EvalForge:** an illustrative case-study walkthrough is not a public deployment of the private grading system.
- **Grid Flex:** the linked publicly reachable web interface operates on synthetic factory scenarios and does not control physical equipment.
- **EduPredict AI:** illustrative student assessment data and early-warning visualizations do not establish real student-risk accuracy.

The official Software Engineer resume is the user-supplied PDF served under `public/resume/`. Never regenerate or silently replace it from older artifacts. Validate the resume and certificate links in a signed-out browser before sending them to recruiters.
